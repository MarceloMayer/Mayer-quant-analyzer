# Mayer-quant-analyzer
Sistema web para importar, analisar e comparar resultados de backtests de estratégias automatizadas exportados do MetaTrader 5.  O projeto permite avaliar estratégias individualmente e em portfólio, calculando métricas como resultado líquido, drawdown, taxa de acerto, profit factor, payoff, curva de capital e performance mensal consolidada.
